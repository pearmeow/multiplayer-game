# multiplayer game

2 player coop multiplayer game

## Current ideas

2d top down game where one player can move obstacles and one  
player can shoot enemies  
Shooting player can shoot obstacles and other player can collect
pickups and upgrades  
Both players share a resource bar so they have to handle shooting  
and moving in an efficient manner  
2nd player might just be a vision cone where they handle where  
the first player shoots/collects items and they use two keys to  
control the rotation of the cone
