# Audio sources

All listed source pages identify the material as CC0. The playable copies are registered in the GameMaker Sounds folder.

| Use | Author | Source | File used |
|---|---|---|---|
| Floor 1 | yd | https://opengameart.org/content/dungeon-ambience | dungeon002.ogg |
| Floor 2 | Paul Wortmann | https://opengameart.org/content/dark-cavern-ambient | dark_cavern_ambient_002.ogg |
| Floor 3 | congusbongus | https://opengameart.org/content/lost-in-a-bad-place-horror-ambience-loop | lost.ogg |
| Hunter and enemy steps | GboxMikeFozzy | https://opengameart.org/content/footsteps-0 | 01-footstep.ogg through 04-footstep.ogg |
| Enemy alert | Ogrebane | https://opengameart.org/content/monster-sound-pack-volume-1 | monster-10.wav |
| Hunter hit | ArcadeParty | https://opengameart.org/content/zombie-skeleton-monster-voice-effects | humanYell3.wav |
| Heartbeat | bart | https://opengameart.org/content/heartbeat-sounds | heartbeat_slow_0.wav |

The effects were converted to mono, 44.1 kHz, 16-bit PCM. The ambience tracks retain their original Ogg audio. Mix, falloff and heartbeat smoothing are configurable in the object Variable Definitions. Each floor's music is selected by its hunter instance's `floor_bgm` override.

The victory chime and failure flatline are original synthesized cues.
